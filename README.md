# Multiplayer Dice Game

This repository contains the implementation for a simple multiplayer dice game using WebSockets.
The primary focus of this project was to **demonstrate and practice the implementation of WebSocket communication** for a real-time, interactive application.

## Features

* **Real-time Multiplayer:** Enables two players to connect and play against each other in real-time.
* **Simple Dice Rolling:** Each player rolls two standard six-sided dice.
* **Automatic Winner Determination:** The server compares the total of each player's rolls and declares the winner (or a tie).
* **Lobby Management:** Restricts the game to a maximum of two concurrent players. And game won't play if there is only 1 player.
* **Real-time Chat (Planned):** Future implementation will include a real-time chat feature allowing players to communicate during the game.

## Technologies Used

### Back-end
* **Java (JDK 21)**
    * Spring Boot: A framework for building production-grade Spring based Applications.
    * Spring WebSocket: Provides support for WebSocket-based communication within Spring applications.
    * Jackson: Used for JSON serialization and deserialization
    * Maven: This project uses Maven for dependency management and building.
